# 🚀 AlgoVerse AI  
### 3D AI-Powered Data Structures & Algorithms Visualization Platform

AlgoVerse AI is an interactive learning platform that transforms abstract Data Structures and Algorithms into **immersive 3D visual experiences**, generated dynamically using Artificial Intelligence.

---

## 💡 Inspiration
Data Structures and Algorithms are the backbone of computer science, yet they remain difficult to understand due to abstract concepts like pointers, memory flow, and recursion being taught through static 2D diagrams.

AlgoVerse AI was built to **bridge the gap between code and intuition** by allowing students to *see* algorithms execute in a dynamic 3D environment.

---

## 🎯 What It Does
AlgoVerse AI helps learners understand algorithms visually instead of memorizing them.

### 🔹 Key Capabilities
- 📚 **Curated 3D Algorithm Library**
  - Arrays: Two Sum, Sort Colors, Majority Element
  - Linked Lists: Reverse List, Palindrome Check, Cycle Detection
- 🤖 **AI Algo Builder**
  - Accepts algorithm problems in plain English
  - Generates optimized **C++ logic**
  - Produces structured **JSON-based 3D animation steps**
- 🎮 **Interactive Learning**
  - Step-by-step playback
  - Pause, replay, and control animation speed
  - Real-time code highlighting synced with visuals

---

## 🧠 Core Innovation
Unlike traditional platforms with fixed visualizations, AlgoVerse AI uses **Google Gemini 3.0 Pro Preview** to dynamically create **new 3D visualizations for unseen problems**, enabling limitless algorithm exploration.

---

## ⚙️ Tech Stack
| Layer | Technology |
|------|------------|
| Frontend | React, Vite |
| 3D Engine | Three.js (React Three Fiber) |
| AI | Google Gemini 3.0 Pro Preview API |
| Styling | CSS3 (Glassmorphism UI) |

---

## 🛠️ How It Works
1. User enters a problem statement (e.g., *"Detect cycle in linked list"*)
2. AI analyzes the problem and generates:
   - Optimized C++ logic
   - Step-wise 3D animation instructions (JSON)
3. The 3D engine renders:
   - Nodes, pointers, and transitions
   - Live pointer movements and structural changes
4. User controls playback to learn at their own pace
